# چطور به مدل چیز یاد بدهم — راهنمای گام‌به‌گام

مدل چهار «سطح یادگیری» دارد که از سریع‌ترین/موقتی‌ترین به کندترین/دائمی‌ترین
مرتب شده‌اند. برای هر کاری سطح مناسب را انتخاب کن.

| سطح | ابزار | سرعت | ماندگاری | مصرف محاسبه |
|---|---|---|---|---|
| ۱. زمینه (context) | خودِ پرامپت | فوری | فقط همان گفت‌وگو | صفر |
| ۲. حافظه‌ی بازیابی | `slm memory add` | فوری | دائمی (فایل) | صفر |
| ۳. یادگیری مداوم + بازخورد | داشبورد / چت | ثانیه‌ها تا دقیقه‌ها | در **وزن‌ها** | کم |
| ۴. آموزش مرحله‌ای | `train_stages.sh` | دقیقه‌ها تا ساعت‌ها | در وزن‌ها | زیاد |

---

## سطح ۱ — زمینه: فقط بگو

```bash
slm chat --ckpt models/demo-fa.slm --tokenizer models/demo-fa.slmtok
you> <|system|>تو یک دستیار فارسی‌زبان هستی که کوتاه جواب می‌دهد.<|user|>سلام
```

هیچ چیز ذخیره نمی‌شود. برای آزمایش سریع لحن و قالب خوب است.

---

## سطح ۲ — حافظه: چیزی بنویس که همیشه یادش بماند

```bash
# نوشتن
slm memory --file runs/memory.jsonl add "اسم من صالح است و روی پروژه‌ی slm کار می‌کنم" --tags user
slm memory --file runs/memory.jsonl add "پروژه‌ی من با C++ نوشته شده و ۲۵۰ میلیون توکن دیده" --importance 2

# دیدن و جست‌وجو
slm memory --file runs/memory.jsonl list
slm memory --file runs/memory.jsonl search "زبان پروژه من چیست؟"

# استفاده در چت (حافظه‌ی مرتبط خودکار به پرامپت تزریق می‌شود)
slm chat --ckpt models/demo-fa.slm --tokenizer models/demo-fa.slmtok \
         --memory runs/memory.jsonl
```

در داشبورد: پنل «long term memory» یک جعبه‌ی متن دارد؛ در داشبورد ترمینالی
`m <متن>` همان کار را می‌کند.

**چطور کار می‌کند؟** هر حافظه با سه‌گرام‌های کاراکتری هش می‌شود (زبان‌مستقل، بدون
نیاز به مدل)، و در هر نوبت چت، ۳ حافظه‌ی شبیه‌ترین به سؤال به‌شکل یک بلوک
`<|system|>` جلوی پرامپت گذاشته می‌شود. یعنی مدل **بی‌آموزش** از آن استفاده می‌کند.

نکته: حافظه‌ی بازیابی برای *واقعیت‌ها* عالی است («اسم من…»، «آدرس سرور…»)، اما
برای *مهارت* («این‌طور کد بنویس») سطح ۳ یا ۴ لازم است.

## سطح ۳ — یادگیری زنده: سه تردی که همان لحظه یاد می‌گیرند

```bash
slm dashboard --ckpt models/demo-fa.slm --tokenizer models/demo-fa.slmtok \
  --config configs/slm-fa.conf \
  --mix fa=data/tokens/fa.bin:0.5,py=data/tokens/py.bin:0.25,en=data/tokens/en.bin:0.15,bridge=data/tokens/bridge.bin:0.10
```

سه راه برای یاد دادن، همه هم‌زمان:

### الف) هر چه بنویسی، یاد می‌گیرد (continual)
هر پیام تو در بافر ترد یادگیری مداوم می‌رود. با رسیدن ۲ نمونه (یا ۲۵ ثانیه)
یک دور fine-tune سبک اجرا می‌شود: `lr=1.5e-5` و ۵۰٪ داده‌ی replay از کورپوس
اصلی تا زبان‌های دیگر فراموش نشوند.

### ب) امتیاز بده (feedback / DPO)
زیر هر پاسخ دکمه‌های ۱..۵ هست (در ترمینال: `r 5`). دو پاسخ متفاوت به یک سؤال با
امتیازهای مختلف = یک **جفت ترجیحی** و ترد DPO آن را اعمال می‌کند. این قوی‌ترین
راه برای اصلاح *سبک* و *ترجیح* است.

> اگر یک سؤال را دوباره بپرسی، seed تازه است پس پاسخ متفاوت می‌شود؛ دقیقاً همین
> چیزی است که جفت می‌سازد.

### ج) حافظه را به وزن‌ها تبدیل کن (consolidation)
دکمه‌ی «teach the weights» در پنل حافظه (در ترمینال: `t`) حافظه‌ها را به ترد
یادگیری مداوم می‌فرستد تا در پارامترها بنشینند. شمارنده‌ی `taught` هر حافظه
نشان می‌دهد چند بار این کار انجام شده.

### چه چیزی تضمین می‌کند خراب نشود؟
هر آپدیت این سه ترد از coordinator عبور می‌کند: ادغام Fisher/TIES/PCGrad، سپس
گیت holdout **برای هر زبان جدا**. اگر یاد دادن چیزی به فارسی، پایتون را بدتر کند،
آپدیت **رد و rollback** می‌شود و دلیلش در `audit.jsonl` می‌آید. یعنی می‌توانی
بی‌محافظه آزمایش کنی.

## سطح ۴ — آموزش مرحله‌ای: یاد دادن یک دامنه‌ی کامل

### گام ۰: داده
```bash
./scripts/update_data.sh --budget-mb 4000 --share "fa=0.6,en=0.1,py=0.3"
```
این اسکریپت دانلود → تمیزکاری/dedup → آموزش توکنایزر → توکنایز به فایل باینری
mmap را انجام می‌دهد. برای داده‌ی خودت: فایل متنی‌ات را در `data/` بگذار و
`--in myname=data/mine.txt` را به `slm tokenize` بده.

### گام ۱: سه مرحله‌ی آموزش
```bash
./scripts/train_stages.sh --steps 4000
# مرحله ۱ (۷۰٪): پیش‌آموزش عمومی   fa 50 / py 25 / en 15 / bridge 10
# مرحله ۲ (۱۵٪): anneal کدمحور     py 55 / fa 20 / en 15 / bridge 10، lr کمتر
# مرحله ۳ (۱۵٪): SFT دستوری        داده‌ی دستوری + bridge + مقداری داده‌ی واقعی
```
هر مرحله از چک‌پوینت قبلی resume می‌کند و شمارنده‌ی گام را حفظ می‌کند، پس
زمان‌بندی WSD و برنامه‌ی رشد معنا می‌مانند. هر وقت خواستی قطع کن و بعداً ادامه بده.

### گام ۲: یاد دادن یک مهارت خاص (fine-tune هدفمند)
فرض کن می‌خواهی مدل «خلاصه‌نویسی فارسی» یاد بگیرد:

```bash
# ۱) داده بساز: هر نمونه یک خط، با قالب چت
python3 - <<'EOF' > data/summ.txt
pairs = [("متن بلند ...", "خلاصه: ...")]
for src, dst in pairs:
    print(f"<|user|>این متن را خلاصه کن:\n{src}<|assistant|>{dst}<|endoftext|>")
EOF

# ۲) توکنایز
slm tokenize --tokenizer data/tok.slmtok --in summ=data/summ.txt --out-dir data/tokens

# ۳) fine-tune با replay (تا چیزی فراموش نشود) و lr کوچک
slm pretrain --resume run/fa.slm --out run/fa-summ.slm --tokenizer data/tok.slmtok \
  --config configs/slm-fa.conf --lr 2e-4 --steps 300 \
  --mix summ=data/tokens/summ.bin:0.5,fa=data/tokens/fa.bin:0.25,py=data/tokens/py.bin:0.15,bridge=data/tokens/bridge.bin:0.10

# ۴) بررسی که چیزی خراب نشده
slm eval --ckpt run/fa-summ.slm --tokenizer data/tok.slmtok \
  --mix fa=data/tokens/fa.bin,py=data/tokens/py.bin,en=data/tokens/en.bin
```

قاعده‌ی طلایی: **سهم داده‌ی جدید را از ۵۰٪ بیشتر نکن** و بقیه را replay بگذار.
اگر بیشتر بگذاری، مدل مهارت جدید را می‌گیرد و مهارت قبلی را از دست می‌دهد.

### گام ۳: بزرگ‌کردن مدل به‌جای شروع از صفر
اگر مدل ظرفیت کم دارد، لازم نیست از صفر آموزش بدهی — لایه اضافه کن:

```bash
slm pretrain --resume run/fa.slm --out run/fa-big.slm ... \
  --grow "0:2,800:2"      # همین ابتدا ۲ لایه، در گام ۸۰۰ دو لایه‌ی دیگر
```
لایه‌ی جدید با تصویرسازی همانی اضافه می‌شود (وزن‌های خروجی باقی‌مانده صفر)، پس
loss در لحظه‌ی رشد **جهش نمی‌کند**. در لاگ می‌بینی:

```
>>> GROWTH at step 600: 6 -> 7 layers, 12.441M -> 13.990M parameters (+12.5%)
```

## چطور بفهمم واقعاً یاد گرفته؟

```bash
# ۱) پرپلکسیتی و bits/char هر زبان جدا
slm eval --ckpt run/fa.slm --tokenizer data/tok.slmtok --mix fa=...,en=...,py=...

# ۲) تداخل زبانی + اعتبار کد
slm langcheck --ckpt run/fa.slm --tokenizer data/tok.slmtok --mix ... --samples 16

# ۳) مجموعه‌ی canary خودت: ۲۰-۵۰ پرسش ثابت، بعد از هر مرحله diff بگیر
for q in "پایتخت ژاپن کجاست؟" "عنکبوت چند پا دارد؟"; do
  slm chat --ckpt run/fa.slm --tokenizer data/tok.slmtok --prompt "<|user|>$q<|assistant|>" --max-new 40 --temp 0
done
```

سه علامت خطر:
* `interfere` بالای ۲۵٪ → مدل دارد زبان‌ها را قاطی می‌کند.
* افت `holdout` یک زبان بعد از یاد دادن چیز جدید → سهم replay را زیاد کن یا LR را کم.
* افت شدید آنتروپی → شروع فروپاشی؛ در حالت زنده coordinator خودش جلویش را می‌گیرد.

## اشتباهات رایج

| اشتباه | نتیجه | راه درست |
|---|---|---|
| fine-tune فقط روی داده‌ی جدید | فراموشی همه‌چیز | ۵۰٪ replay |
| LR پیش‌آموزش برای fine-tune | خرابی مدل در چند گام | ۱/۵ تا ۱/۱۰ آن |
| عوض کردن توکنایزر بعد از آموزش | مدل بی‌مصرف می‌شود | توکنایزر را از اول درست انتخاب کن |
| یاد دادن با ۵ نمونه | چیزی یاد نمی‌گیرد (یا حفظ می‌کند) | حداقل چند صد نمونه، یا از حافظه‌ی سطح ۲ استفاده کن |
| انتظار دانش دنیا از مدل ۱۴M | جواب‌های اشتباه با اعتماد | برای دانش از حافظه/RAG استفاده کن، از وزن‌ها نه |
